# 🎒 АйШпора (@aishpora_bot) — Официальный лендинг

Современный, высококонверсионный адаптивный лендинг для вирусного Telegram-бота **«АйШпора»** — ИИ-решебника и калькулятора по фото для школьников и студентов.

## 🚀 Возможности лендинга
- **Интерактивный симулятор**: Позволяет протестировать работу нейросети прямо в браузере с переключением 3 стилей («Как для бро», «По ГОСТу», «Шпора») по предметам: алгебра, физика, геометрия, химия, проценты.
- **Инлайн-демонстрация**: Интерактивный мокап вызова бота `@aishpora_bot` в беседе класса.
- **Калькулятор времени и нервов**: Геймифицированный ползунок расчета сэкономленных часов.
- **SEO & AI Search**:
  - Полная семантическая разметка HTML5.
  - Schema.org JSON-LD (`SoftwareApplication`, `FAQPage`, `HowTo`, `AggregateRating`).
  - Стандарт `llms.txt` для индексации нейросетями (Perplexity, ChatGPT, Claude).
  - Оптимизированные `robots.txt` и `sitemap.xml`.
- **Полная адаптивность**: Безупречно отображается на мобильных устройствах, планшетах и 4K-мониторах.
- **Неоновый киберпанк-дизайн**: Фирменный маскот, темная тема, плавающие математические символы, анимации свечения.

## 🌐 Деплой (GitHub Pages / Vercel / Netlify / Nginx)
Проект является чистой статикой (HTML + CSS + JS) и готов к деплою на любой платформе:
- **GitHub Pages**: Включите Settings -> Pages -> Source: Deploy from a branch (`main` / root).
- **Vercel / Netlify / Cloudflare Pages**: Разворачивается за 1 клик без сборки.
- **Nginx**: Положите файлы в корень раздачи веб-сервера.
